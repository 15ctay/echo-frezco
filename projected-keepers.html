How these were picked

  1. Stats: 2026 regular-season player totals from the public Sleeper API (Sleeper API /v1/stats/nfl/regular/2026/{week}, Weeks 1-5 summed), pulled Oct 18, 2026, 2:54 PM ET. Season to date, so a player who missed games is penalized for it.
  2. Points: each player's raw stats are rescored with this league's rules: full PPR (1/rec), 6-pt passing TDs, 25 pass yds/pt, −2 INT, 10 rush/rec yds/pt, 6-pt rush/rec/return TDs, −2 fumble lost, 2 per 2-pt conversion. "League pts" is what we rank by. "Std PPR" is Sleeper's standard full-PPR total (4-pt pass TDs), shown for reference. They only differ for QBs.
  3. Matching: every rostered QB/RB/WR/TE is matched to Sleeper by normalized name plus NFL team, falling back to name only when it's unique. All rostered players matched.
  4. Picking: the top-scoring QB, RB, WR and TE on each roster fill the four position spots. The 3 highest-scoring players left, at any position, fill FLEX. Ties go to the player drafted later.
  5. Kickers and defenses aren't considered. Injury status is noted but doesn't change anything. A player on IR keeps his points.
  6. Draft round is context only, not a keeper cost. This page doesn't apply any round penalty because the league hasn't published one.
